feat: Windows 向け Desktop リリーススクリプト（PowerShell 版）を追加（#218）

scripts/release-desktop.sh は bash 前提で、Windows 環境では .sh を直接実行できない。
同じ用途の PowerShell 版 scripts/release-desktop.ps1 を追加した。

- -Targets all / windows / jar で個別指定（既定は all = MSI + JAR）
- -DryRun でビルドのみ。タグ未打ちでも実行できる
- バージョン導出は git describe --tags を優先し、無ければ origin/main のタグにフォールバック
  （release-desktop.sh と同じ vX.Y.Z 規則）
- Release ノートは whatsnew + ダウンロード一覧 + 署名差分 / SmartScreen の注意を自動生成

Windows PowerShell 5.1 対応のため 2 点対処している:
- ファイルを BOM 付き UTF-8 で保存（5.1 は BOM なし UTF-8 を誤読する）
- gh の --jq は jq 構文なので PowerShell のエスケープでは書けない。--json を取り、
  ConvertFrom-Json で整形する方に倒した

検証: -Targets jar / -Targets windows を -DryRun で実行し、
Nostrism-0.6.21-jar.jar と Nostrism-0.6.21-windows.msi の生成を確認。

README のビルド手順とディレクトリ一覧に追記。
