feat: Desktop ネイティブパッケージのリリーススクリプトを追加（#218）

scripts/release-desktop.sh を追加。Windows MSI / Linux DEB+RPM / macOS dmg / 汎用 JAR を
ビルドして GitHub Releases へ添付する。既存の release-github.sh（Android APK + macOS dmg）
と同じ「プレビュー配布」枠で、扱いを揃えている。

- 実行プラットフォームを uname -s で判定し、TARGETS で個別指定も可能
  （TARGETS=windows / linux / mac / jar、複数指定可）
- バージョン付きのファイル名にリネームして添付する
  （Nostrism-<version>-windows.msi / -linux.deb / -linux.rpm / -macos.dmg / -jar.jar）
- DEB/RPM は fakeroot / rpm が無い環境ではスキップして警告（ビルド全体は止めない）
- Release ノートは whatsnew + ダウンロード一覧 + 署名差分の注意を自動生成
  （既存版と相互更新できない旨、未署名 dmg の右クリック→開く を毎回 注記）
- DRY_RUN=1 で Release を作らずにビルドのみ

README のビルド手順とディレクトリ一覧に追記。

検証: DRY_RUN=1 で TARGETS=jar / TARGETS=windows を実行し、
Nostrism-0.6.20-jar.jar (103MB) と Nostrism-0.6.20-windows.msi (124MB) の生成を確認。
