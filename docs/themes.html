テーマの正体

1つのテーマは Nostr の kind:30078 イベント1件です。t タグに nostrism-theme が付いており、中身は背景・文字・アクセントの3色。面や境界線はアプリ側で自動的に導出されます。

使うには

アプリの「設定 → 表示 → テーマ」を開き、ストアタブから直接選べます。このページの共有コードを「カスタマイズ」タブの共有コード欄に貼り付けても取り込めます。

公開するには

アプリで3色を決めて「テーマストアに公開」を押すだけです。あなたの鍵で署名されたイベントがリレーへ流れ、このページにも並びます。
