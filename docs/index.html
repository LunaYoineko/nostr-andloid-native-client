できること

読む速度に合わせて組み替えられる

カラムは自由に追加・ピン留め・並べ替えできる。フォロー中もハッシュタグも、特定の人の投稿も、キーワード検索も、すべて同じ「カラム」として扱う。

01 / デッキ

カラムを並べる

フォロー中・ハッシュタグ・通知・DM・パブリックチャット・検索。開いたスレッドも一時カラムとして横に開き、ピン留めで常設にできる。

02 / 操作

キーボードで動かす

j k で投稿、h l でカラム移動。n 新規投稿、r 返信、f リアクション、b ブックマーク。? で一覧。

03 / 見た目

3色で塗り替える

背景・文字・アクセントの3色を決めれば、面や境界線は自動で導出される。作った配色はテーマストアへ公開でき、他の人のものを取り込める。

04 / 絵文字

カスタム絵文字

自分の絵文字リストをアプリ内で編集。リアクションにも本文にも使える。GIF やアニメ WebP もそのまま動く。

05 / 送金

アプリ内 Zap

Nostr Wallet Connect でウォレットを繋ぐと、外部アプリに飛ばずに Zap できる。送金は毎回確認する。

06 / 取得

アウトボックス

相手が実際に使っているリレー（NIP-65）からも取りに行くので、自分の接続先に無い投稿も拾える。

テーマストア

誰かが作った配色を、そのまま着る

テーマは Nostr のイベントとして公開される。だから特定のサーバーに依存せず、アプリを入れていなくてもブラウザから中身を見られる。

対応

Nostr の仕様に沿って作られている

鍵はあなたの端末にあり、開発者のサーバーは存在しない。外部の署名アプリ（NIP-55）にも対応しているので、アプリに秘密鍵を渡さずに使える。
