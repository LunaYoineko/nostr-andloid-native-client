docs: README に Gradle タスク一覧を追加

ビルド手順が実際の gradle タスクに追いついていなかったので整理した。
今回 Desktop 対応で追加された package* タスク群と主要なタスクを
カテゴリ別に整理し、出力先と必要な外部ツールを明記した。

- コンパイル・テスト（compileKotlin* / desktopTest / desktopMainClasses）
- Android（assembleDebug / assembleRelease / installDebug）
- Desktop（run / packageUberJarForCurrentOS / packageMsi / packageDeb / packageRpm /
  packageDmg / createDistributable）— 出力パスと fakeroot・rpm・jpackage の要否を明記
- 補助（generateWindowsIco / clean）

あわせて以下を追記:
- ネイティブパッケージは生成できるプラットフォームで実行する必要（MSI=Windows、DEB/RPM=Linux）
- jpackage 入り JDK 21 が必要で、`-PpackagingJavaHome="$JAVA_HOME"` を明示的に渡す
- リリーススクリプトは HEAD がバージョンタグ上である必要（未タグ時は警告して停止、-DryRun は例外）
- PowerShell 版（Windows 向け）の一覧

タスク名は `:composeApp:tasks --all` で実在を確認済み。
